# 航班信息应用 (Flight Info App)

这是一款功能全面的 Android 应用程序，旨在为用户提供实时航班信息、预订和跟踪功能，提升旅行体验。

## 主要功能

*   **航班搜索**: 用户可以轻松搜索全球范围内的航班，获取详细的航班信息，包括起飞/到达时间、航空公司、航班号等。
*   **航班预订与座位选择**: 提供流畅的航班预订流程，并允许用户在预订时选择自己喜欢的座位。
*   **旅行建议**: 根据用户的目的地提供个性化的旅行建议，包括天气、景点和当地活动。
*   **天气信息集成**: 集成实时天气数据，帮助用户更好地规划行程。
*   **航班状态通知**: (即将推出) 用户可以跟踪航班，并在航班状态（如延误、取消、登机口变更）发生变化时收到实时推送通知。

## 技术栈

*   **架构**: MVVM (Model-View-ViewModel)
*   **依赖注入**: Hilt
*   **网络请求**: Retrofit & Gson
*   **数据库**: Room
*   **UI**: Material Design Components, RecyclerView
*   **导航**: Jetpack Navigation Component
